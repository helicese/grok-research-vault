# 营销创意生成与互动玩法

公司内部要做一套「快速生成创意素材 + 营销/互动玩法」的方案。这个主题收集业界已经在跑的产品与战役，用来对照能力边界，不把平台自报的效果数字当成可直接照搬的基准。

## 范围

- 营销场景里生成图、文案、视频/动画、数字人的产品与工作流。
- 互动玩法：试玩广告、H5/裂变、生成式共创、虚拟试穿、信息流直玩。
- 这些能力是否已经接上审核、投放和效果回流。

不覆盖：通用绘画/视频模型的参数对比，以及与营销投放无关的纯内容社区。
